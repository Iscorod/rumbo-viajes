# Rumbo

Rumbo es una pequeña aplicación web para organizar los días, vuelos, tiempos de aeropuerto, traslados, alojamiento y planes de una escapada. Calcula el tiempo libre a partir de los bloques ocupados y conserva los cambios en el almacenamiento local del navegador.

## Uso

Abre `index.html` en un navegador moderno. Edita el viaje desde el botón superior, añade eventos y usa los controles del calendario para revisar el detalle diario. El botón de exportar descarga una copia JSON del itinerario.

No se necesita instalación, cuenta ni servicio externo. En un dispositivo nuevo, el navegador parte del viaje de ejemplo.

## Publicación

El proyecto es estático y se puede importar directamente en Vercel como una aplicación sin framework, con `index.html` en la raíz.
